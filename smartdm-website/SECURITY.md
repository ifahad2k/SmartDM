# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability or potential threat in SmartDM, please **do not open a public issue**.

Instead, report security concerns directly to the maintainer via private security advisory or email contact on GitHub:
- Primary repository: [https://github.com/ifahad2k/SmartDM](https://github.com/ifahad2k/SmartDM)
- GitHub Security Advisories: [https://github.com/ifahad2k/SmartDM/security/advisories](https://github.com/ifahad2k/SmartDM/security/advisories)

Please include:
1. Description of the vulnerability and potential impact.
2. Steps or proof-of-concept to reproduce the vulnerability.
3. Affected platforms or browser extensions.

We aim to respond to security reports within 48 hours and work with reporters on coordinated disclosures.
