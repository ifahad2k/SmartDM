Common fixes

Resolve integration issues quickly.

SmartDM does not intercept browser downloads

Verify that native host messaging scripts are registered and SmartDM is running in your background system tray.

Video formats or playlists fail to extract

Update `yt-dlp` from SmartDM's internal updater tab to ensure support for changing site extractors.

A segmented download cannot resume

Ensure the remote server supports HTTP byte ranges (`Accept-Ranges: bytes`). If temporary download URLs expired, refresh the link in SmartDM.

FAQ

Answers before you install.

Common questions about platform support, licensing, and privacy.

Is SmartDM completely free?

Yes. SmartDM is 100% free and open-source under GNU GPL-3.0. There are no paid tiers, ads, or hidden telemetry.

Do I need to enable AI features?

No. AI cataloging is completely optional. You can connect a free Gemini API key, run a local Ollama model, or keep AI turned off.

Which operating systems are supported?

SmartDM supports 64-bit Windows 10/11 and Linux (via AppImage and DEB packages).

How does browser download interception work?

SmartDM uses lightweight browser extensions combined with a native messaging host to capture download requests automatically.

How do I verify official release files?

Run Get-FileHash -Algorithm SHA256 SmartDM-Setup-v1.0.0.exe and check it against the published SHA-256 checksum on GitHub.
