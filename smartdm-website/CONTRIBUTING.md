# Contributing to SmartDM

Thank you for your interest in contributing to SmartDM! As an open-source project, SmartDM welcomes community contributions, bug reports, documentation updates, and feature proposals.

## How to Contribute

### 1. Reporting Bugs
- Before submitting a bug report, check existing issues on GitHub.
- Use the structured [Bug Report Template](https://github.com/ifahad2k/SmartDM/issues/new?template=bug_report.yml).
- Include operating system version, SmartDM version, and clear steps to reproduce.
- **Do not post private credentials, access tokens, or sensitive personal logs in public issues.**

### 2. Suggesting Features
- Submit feature suggestions via the [Feature Request Template](https://github.com/ifahad2k/SmartDM/issues/new?template=feature_request.yml).
- Explain the problem your proposed feature solves and any alternative solutions considered.

### 3. Submitting Pull Requests
1. Fork the repository and create a feature branch off `main`.
2. Ensure all changes adhere to existing project code formatting standards.
3. Test your changes locally (run unit tests or local static website validation).
4. Commit your work with concise, descriptive commit messages.
5. Open a Pull Request referencing the related GitHub issue.

## Code of Conduct
Please note that this project is governed by our [Code of Conduct](CODE_OF_CONDUCT.md). All contributors are expected to uphold these standards.
